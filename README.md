## Project Overview

This project is intended to be an example of a proper Software Engineering product, mainly something that actually tackles to solve a problem. It is a problem that I have made for myself, and intend to make this a solution for myself (and maybe for others later). This is an Expense Tracking Application (not really named yet), that is meant to be extremely in depth for how someone would want to manage their expenses. I have found that many applications that are for budgeting, are either a spreadsheet in an excel file, which is really annoying to use, can get unnecessarily large, and doesnt really have the power to do what I wanted to do with it. The other option is to use a mobile application, but the problem with that is that most the good ones are paid, and frankly, I just dont want to **pay** to budget my own way. So thats where this project comes in, its intent is something that anyone can use to budget their life expenses for free.

## Features Overview

### Expenses

-   Create an expense with a title, amount, category, and a date. ✅︎
-   A quick add for expenses, that only requires an amount and a category. It assumes the date to be day of, and keeps the title empty. ✅︎
-   Ability to categorize expenses, and assign colors to these categories. ✅︎
-   Ability to edit and delete expenses and categories. ✅︎

### Budgeting

This feature is currently in development. Here are the current plans:

-   Create a monthly budget that allows you to set budgets for categories. ☐
-   View monthly budgets and the overview of how much has been spent. ☐
-   Adjust budget based on a fixed amount, or a percentage, per category. ☐
-   Setup anticipated weekly/monthly payments that will automatically deduct from the budget. ☐
-   Input income based on a salary, or hourly basis that will dynamically change metrics. ☐

### Metrics

This feature is yet to be developed, but here are some of my ideas:

-   View expenses by category
-   View trends of spending per category or by month for the year
-   View yearly report for expenses
